# Utilies for data storage, processing (tokenization), polynomial manipulations and metrics
## \_\_init\_\_.py
Assembled functions provided for calling outside the directory
## args.py
Arguments passed by keyboard inputs by calling `argparse.ArgumentParser()`
## charset_verify.mpl
Maple verification of characteristic sets of polynomials with all integer coefficients called by `poly.py`
## dataloader.py
Organization of data loaders for training, validation and inference of models
## finite_verify.mpl
Maple verification of characteristic sets of polynomials with all coefficients in finite field called by `poly.py`
## int.py
A specially designed container for 32-bit integer to avoid huge memory consumption led by `eval(BIG_NUM)` in python
## poly.py
Utilies concerning polynomial manipulations and metrics
## storage.py
Data organization of data samples from different types of datasets
## token.py
Tokenization schemes
